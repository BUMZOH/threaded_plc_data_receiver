# モータ電流値 受信アプリ GUI版

## ファイル

- `app.py` : Python本体
- `index.html` : pywebview画面
- `style.css` : 最小限のCSS
- `script.js` : 監視開始・停止ボタンの処理

## 操作

1. アプリを起動する
2. 「監視開始」を押すとPLC要求監視を開始する
3. 「監視停止」を押すとPLC要求監視を停止する
4. ウィンドウ右上の「×」でアプリを終了する

「監視停止」は新しい要求の監視を停止します。
すでに開始済みのモータデータ受信・CSV保存・PLC完了通知は最後まで実行します。

## 必要パッケージ

```text
pywebview
```

既存の `common_lib_mw/kv_com.py` は従来どおり必要です。
