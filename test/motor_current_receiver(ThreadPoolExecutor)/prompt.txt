新しいアプリをつくります

- 設備のモータ電流値をPLCから受信
- モータは3つ(モータ1～モータ3)
- PLCはキーエンスKV-5000
- PLCからの受信は独自モジュールkv_com.pyを使う(添付します)
- PCはPLCの以下のデバイスを常に監視する
   B10.0 : モータ1用 (PCへ受信要求)
   B10.1 : モータ2用 (PCへ受信要求)
   B10.2 : モータ3用 (PCへ受信要求)
- PCは上記デバイスがONになったタイミングで以下のデータを受信する
   EM30000 - EM31999: モータ1電流値、2Word x 1000点分
   EM32000 - EM33999: モータ2電流値、2Word x 1000点分
   EM34000 - EM35999: モータ3電流値、2Word x 1000点分
- PCはデータ受信完了したタイミングで以下の完了通知用デバイスをONさせる
   B20.0 : モータ1用 (PLCへデータ受信完了通知)
   B20.1 : モータ2用 (PLCへデータ受信完了通知)
   B20.2 : モータ3用 (PLCへデータ受信完了通知)
- PLCはPCが受信完了した後にB10.0-B10.2およびB20.0-B20.2をOFFさせる
- EMデータの受信はサブスレッドで実行する(メインスレッドはB10.0-B10.2)の監視
- PCは受信したデータをmotor1～motor3というフォルダに保存。
- CSVファイルはmotor1_20260805_110425.csvのようにモータ名とタイムスタンプにする
- UIはコンソールでOK
